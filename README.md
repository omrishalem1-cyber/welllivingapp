# חיים מיטיבים

אפליקציית Android פרטית לניהול אורח חיים מיטיב. התכנון המלא נמצא בתיקיית הפרויקט (`app-planning/`).

## גרסה 0.1: חסימה ונעילת לילה

- **מנוע כללים אחד** (`rules/`): מודול Kotlin טהור שמכריע מתי אפליקציה חסומה. כל מודול עתידי (למשל עבודה עמוקה) יוסיף לו כלל, ולא מערכת חסימה נפרדת. הלוגיקה נבדקת בבדיקות יחידה.
- **מכסות יומיות** לאפליקציות שנבחרו, ו"חסומה" כמחסום בכל פתיחה.
- **מחסום 60 שניות** עם נשימה (4 שניות שאיפה, 6 נשיפה) ומשפט קבוע; אחריו 5 דקות שימוש.
- **חסימת Shorts** ביוטיוב, דרך שירות הנגישות. רשימת מזהי התצוגה ב-`ShortsDetector.kt` עלולה להתיישן עם עדכוני יוטיוב.
- **נעילת לילה 22:30–08:00**: שיחות, שעון מעורר, וואטסאפ ו-Waze זמינים תמיד. פתיחה דחופה בשאלת אימות פותחת ל-15 דקות, ויוטיוב נשאר חסום. מ-05:00 אפשר להצהיר שהיום התחיל.
- **הגנה מפני הסרה** (מנהל מכשיר) בקוד PIN. אותו קוד נדרש גם לכל הקלה בהגדרות.

## בנייה

```
./gradlew :rules:test        # בדיקות מנוע הכללים
./gradlew :app:assembleDebug # app/build/outputs/apk/debug/app-debug.apk
```

הבנייה דורשת Android SDK (compileSdk 35) ו-JDK 17 ומעלה. GitHub Actions בונה את קובץ ה-APK בכל PR ומצרף אותו כ-artifact.

## התקנה בטלפון

1. להעביר את קובץ ה-APK לטלפון ולאשר התקנה ממקור לא ידוע.
2. לפתוח את האפליקציה ← "הרשאות", ולהפעיל את ארבע ההרשאות.
3. אם Android מסרב להפעיל את שירות הנגישות: הגדרות ← אפליקציות ← חיים מיטיבים ← תפריט שלוש הנקודות ← "התרת הגדרות מוגבלות".
4. להגדיר קוד PIN (מומלץ שחבר יבחר אותו) ולהפעיל את ההגנה מפני הסרה.
