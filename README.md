# מאמן קשב (welllivingapp)

גרסה ראשונה ומצומצמת של האפליקציה: מאמן קשב בלבד.

- בחירת סוג פעילות (קריאת מאמר, קריאת ספר, כתיבת עבודה וכו', וגם פעילויות שתוסיף בעצמך).
- לכל פעילות סולם הארכה משלה: מתחילים ב-20 דקות; שני פרקים מושלמים ברצף מעלים את היעד ב-5 דקות, שני פרקים שהופסקו מוקדם ברצף מורידים אותו ב-5 דקות (טווח 10–90).
- במהלך פרק: ספירה לאחור, כפתור "הוסחתי" (גם מההתראה), וסיום מוקדם.
- בסוף פרק: דירוג ריכוז 1–5. מדדים לכל פעילות: שיעור השלמה, הפרק הארוך ביותר, דקות שבועיות, הסחות לכל 10 דקות.

האפליקציה מבקשת הרשאות רגילות בלבד (התראות ושירות טיימר), ללא נגישות או ניהול מכשיר. כל הנתונים נשמרים בטלפון.

## התקנה

הורדת הגרסה העדכנית: https://github.com/omrishalem1-cyber/welllivingapp/releases/download/attention-latest/attention-trainer.apk

כל הבניות חתומות במפתח קבוע (`signing/sideload.jks`), ולכן גרסה חדשה מותקנת כעדכון על הקודמת בלי לאבד נתונים.

## מבנה

- `trainer/` — לוגיקת ההארכה והמדדים בקוטלין טהור, עם בדיקות (`./gradlew :trainer:test`).
- `app/` — אפליקציית Android (Compose).
